# Verificación visual
1. Ejecutar el entorno local, navegar Inicio, Proyectos, un detalle, Acerca de, Bitácora, un artículo, Contacto y 404.
2. Inspeccionar a 360, 768, 1024 y 1440 px; comparar capturas del ANTES y DESPUÉS del mismo proyecto (no con la web ajena como si fuera un clon).
3. Probar menú móvil, FAQ, enlaces, teclado, foco, títulos, contraste, y preferencias de movimiento reducido.
4. Señalar text overflow, elementos solapados, jerarquías inconsistentes, CTAs invisibles y errores de consola.
5. Corregir los problemas detectados, volver a abrir las mismas rutas y registrar resultados verificables.
