# Interfaz y accesibilidad
- Diseño mobile-first con comprobaciones en 360, 768, 1024 y 1440 px.
- Navegación accesible con teclado, estado aria-expanded, foco visible y nombres discernibles para íconos interactivos.
- Mantener tipografía editorial de fuerte jerarquía, ritmo amplio y movimiento moderado; NO clonar el estilo exacto de la web de referencia.
- No incluir imágenes externas o de terceros sin permisos confirmados; ilustraciones CSS/SVG originales.
- Respetar `prefers-reduced-motion`; revisar contraste y evitar animaciones bloqueantes.
